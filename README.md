# Restaurant Billing System

A desktop-based Restaurant Billing System developed using Java Swing and JDBC. The system helps manage restaurant operations such as menu management, order processing, billing, inventory tracking, and user management.

## Features

- User Authentication (Admin, Cashier, Waiter)
- Menu Management
- Order Management
- Table Order Handling
- Bill Generation
- Payment Processing
- Inventory Management
- Sales Reports
- User Management
- Dashboard for Different Roles

## Technologies Used

- Java
- Java Swing
- JDBC
- MySQL
- Eclipse IDE

## Installation

1. Clone the repository

```bash
git clone https://github.com/tanvigit2000245/Restaurent_Billing_System1.git
```

2. Open the project in Eclipse IDE.

3. Configure MySQL database credentials in:

```java
DBConnection.java
```

4. Run:

```java
Main.java
```
